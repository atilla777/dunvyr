# Начальные знания карты

Контекст: `dunvyr-kye.5`; принятое архитектурное решение для начальной карты без перемещения и раскрытий.

Пакет версии 2 явно содержит начальные обнаруженные локации и известные выходы. Текущая локация считается посещённой; знание не распространяется по графу. Существующие снимки v1 сохраняют исходную каноническую форму и консервативно показывают только начальную локацию без выходов. Валидация ссылок, принадлежности выхода известной комнате и видимости объекта-подписи выполняется до проекции.

`adventures` строит allowlist-проекцию из закреплённого снимка после проверки членства через `campaigns.public`. Известный выход к неизвестной цели передаётся без её идентификатора; клиент изображает отдельную локальную заглушку для каждого выхода, не группируя неизвестные цели. Карта не открывает доступ к иллюстрациям обнаруженных комнат: сцена разрешает только свою текущую иллюстрацию. Сцена, карта и шаблоны персонажей читают одну версию снимка; миграция БД не нужна. Движение, последующие открытия и игровой движок этим решением не вводятся.
