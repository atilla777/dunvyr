# Закреплённое приключение и публичные шаблоны

Контекст: `dunvyr-kye.1`; решение владельца и архитектурное исследование зафиксированы в записи задачи.

## Решение

`adventures` — единственный владелец связи кампании с версией приключения. Он атомарно сохраняет собственный SQLite snapshot нормализованного пакета и байтов ресурсов по ID кампании; `campaigns` не хранит дубликат этой связи. Доступ и роль проверяются через `campaigns.public`, идентичность — через `identity.public`, без чтения чужих таблиц. Конкурентные выборы разрешает ограничение БД: одна версия на кампанию, одинаковый выбор повторяем, несовместимый не заменяет снимок.

Для будущего потребителя `characters` предоставляется только `adventures.public.PinnedTemplatesReader`: навыки и архетипы закреплённой версии, без сценария и скрытых данных. Авторизация вызывающей операции остаётся обязанностью потребителя. HTTP-проекция участника также ограничена публичными метаданными.

## Последствия

Обновление или удаление локального источника не меняет закреплённые данные; стоимость — копирование ресурсов на кампанию. Нет второго владельца и межконтекстного обращения к таблицам, но внутренний reader сам не проверяет членство. Контракт и ограничения реализации — в [спецификации](../../../spec/backend/adventures.md). Полный сюжет и последующие проекции не определяются этим ADR.
