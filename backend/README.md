# Dunvyr backend

Developer notes for the backend skeleton. The canonical fresh-clone flow is
documented in the repository root `README.md`.

The Python version and `uv` version come from the project `mise.toml` at the
repository root; all check tooling (Ruff, mypy, pytest, Import Linter) is a
project dev dependency declared in `pyproject.toml` and pinned in `uv.lock`.
