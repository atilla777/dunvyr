# Общение и память о приключении

## Единый поток

У игроков, NPC и ведущего **один хронологический поток** с визуально различимыми типами сообщений: обычная речь, narrations, результаты действий, голосования и важные события. Игроки обсуждают свободно в real-time, даже когда действует другой персонаж. Возможность отправлять **внутриигровую речь** зависит от актуального состояния персонажа (без сознания/не может говорить — блокировка на сервере).

Обсуждение не является исполнением значимого действия. AI может предложить `ProposedAction` по сообщению, но не выполнить без подтверждения игроком в свой ход.

## Закреплённый контекст текущей сцены

Компактная, всегда доступная панель показывает актуальные **известные** группе сведения: название локации, краткое описание, текущую цель и обнаруженные интерактивные объекты. Она вычисляется из состояния сцены, **не является вручную закреплённым сообщением чата** и обновляется после значимых событий. На телефоне сворачивается до компактной строки/миниатюры.

## Журнал

Простой автоматический журнал: **задачи, открытия, события**. Пополняется **только по явно описанным в сценарии правилам раскрытия фактов/событиям**, а не по свободной оценке «важности» моделью. Не дублировать одно открытие из-за повторного разговора с NPC. Факт, который NPC ещё не разрешено раскрыть, не должен появляться в журнале.

Полный чат сохраняется для продолжения кампании; журнал — структурированное краткое представление только значимых подтверждённых сведений. Отдельные пользовательские заметки, продвинутый поиск, свободные закрепления сообщений — вне MVP.

## TTS

Текст — первичный канал. У реплик AI-ведущего и NPC есть индивидуальная кнопка **«Прослушать»**; автоматическое воспроизведение выключено. Каждый участник управляет звуком **только на своём устройстве**; повторное действие останавливает текущую озвучку. Отсутствие браузерного голоса или ошибка TTS не мешает читать и играть. Для MVP допустим встроенный Web Speech API без отдельного сервера TTS.
