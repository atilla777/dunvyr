# Версия правил создания персонажа

Для `dunvyr-kye.3` `adventures.public.PinnedTemplates` дополнен неизменяемым идентификатором правил создания. Версия 1 сохранённой схемы приключения всегда соответствует `archetype-budget-v1`; неизвестная версия снимка не обрабатывается. Соответствие определяется по сохранённому снимку, не по установленному каталогу. Текущие пакеты, отпечатки и снимки не переписываются.

`adventures` владеет допустимыми шаблонами и возвращает только публичную проекцию, `characters` владеет числовыми ограничениями и проверяет их до записи. Дальнейшее изменение семантики требует новой версии и явного сохранения совместимости ранее закреплённых кампаний; изменение текущей реализации не должно незаметно менять правила старых снимков. Этот выбор не определяет будущую систему развития или окончательный баланс.
