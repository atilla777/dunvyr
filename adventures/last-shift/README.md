# Последняя смена — начало

Оригинальный стартовый пакет Dunvyr, созданный при реализации `dunvyr-kye.1`.
`airlock.png` — оригинальная программно созданная иллюстрация шлюза, подготовленная
AI-исполнителем этой задачи; сторонние изображения и внешние загрузки не использовались.
Это заготовленное локальное изображение, не генерация во время игры.

Пакет содержит только начало расследования, не полное приключение на 1–2 встречи.
Файлы предназначены для сервера; их нельзя публиковать через frontend/static.

Редакция 1.1 (schema 3) добавляет авторское небоевое испытание терминала с
двумя очевидными способами диагностики и декларативными исходами. Проверки и
исходы пока не исполняются: игрокам показывается только доступный каталог.
Сложности и тексты — локальные данные этого шаблона, не утверждённый глобальный баланс.
